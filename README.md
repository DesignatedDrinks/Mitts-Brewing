# Mitt's Brewing Co.

A complete multi-page static website for **Mitt's Brewing Co.**, a Canadian non-alcoholic beer brand built around modern design and carefree nostalgia.

## Pages

- Home
- Our Beers
- Premium Lager
- Our Story
- About
- Find Mitt's
- Shop / Merch
- Journal
- Wholesale
- Contact
- Privacy / Terms

## Local preview

Open `index.html` directly, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

The site is designed for GitHub Pages. In repository settings, set Pages to deploy from the `main` branch root. The included `CNAME` file targets `mittsbrewing.com`.

## Brand direction

- Primary: navy, coastal blue, silver, cream
- Personality: classy, timeless, Canadian, easygoing
- Creative territory: modern design with carefree nostalgia
- Master line: **Mitt's Makes the Moment.**
